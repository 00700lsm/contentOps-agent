# 메타데이터 가이드

이 문서는 콘텐츠 메타데이터 입력 규칙과 오류 코드를 정의한다.

공개 실패의 원인이 상태나 연령 등급이 아니라 메타데이터일 수 있다.

---

## 1. 필수 메타데이터

다음 필드는 필수다.

- contentId
- title
- genre
- ageRating
- runtime
- posterImage
- originalLanguage

필수값이 비어 있으면 공개 워크플로를 진행하지 않는다.

---

## 2. M-03 오류

`M-03`은 필수 메타데이터 누락 오류다.

대표적으로 다음 필드가 비어 있을 때 발생한다.

- title
- ageRating
- posterImage

`M-03`이 발생한 콘텐츠는 메타데이터 검수 화면으로 돌려보낸다.

이 오류는 콘텐츠 차단 상태와 다르다.

`CONTENT_BLOCKED`는 운영 차단이고, `M-03`은 입력값 누락이다.

운영 FAQ의 `OPS-101`과도 구분한다.

`OPS-101`은 공개 파이프라인 실패 코드이고, `M-03`은 메타데이터 검증 코드다.

---

## 3. 기타 오류

- M-01: 콘텐츠 ID 중복
- M-02: 제목 길이 초과
- M-03: 필수 메타데이터 누락
- M-04: 포스터 이미지 비율 오류

오류 코드를 상태값처럼 저장하지 않는다.

오류는 검수 로그에 남기고, 콘텐츠 상태값은 별도의 상태 정책을 따른다.

---

## 4. 공개 전 메타데이터 확인

공개 버튼을 누르기 전에 다음을 확인한다.

1. 필수 필드가 모두 있는가
2. `M-03`이 해소되었는가
3. 연령 등급 필드가 존재하는가
4. 포스터와 제목이 일치하는가

연령 등급 필드가 있다는 것만으로 검수가 완료된 것은 아니다.

등급 검수 완료 여부는 연령 등급 정책을 따른다.
